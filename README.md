# Time Teller
***
## Description
This is a website which allows you to convert any timestamp into your local time, or any preferred timezone.
***
## Features
- Simple interface: just type, the result shows up
- Automatically detects your timezone
- Light mode and dark mode
- 24-hour / 12-hour toggle
- Select any timezone
- Saves your settings
***
## Why I Made This
There used to be a feature on Google where you could type in a timestamp and it would show it converted to your local time, but they have removed it.  
Also, every time converter website I could find is cluttered with useless things everywhere, making it very much not intuitive.  
This website is an attempt at making a simple straightforward time converter.
